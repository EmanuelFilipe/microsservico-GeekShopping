# microsservico-GeekShopping

### English
Building an E-Commerce with Microservices in MVC Architecture using C# 6. Each part of the application is managed by a microservice, e.g., product CRUD, shopping cart, coupon application, among others.

- Database: SQL Server
- Messaging: RabbitMQ
- Gateway: Ocelot
- Identity: Identity Server

********************************************************

### Português
Construção de E-Commerce com microsserviços na arquitetura MVC com C# 6. Cada parte da aplicação é gerenciado por um microsserviço, ex: CRUD de produtos, carrinho de compras, aplicação de cupons entre outros.
- Banco de dados em SQL Server
- mensageria RabbitMQ
- Gateway Ocelot
- Identity Server
